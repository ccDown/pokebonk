# PokéBonk 离线版

对 [pokebonk.com](https://pokebonk.com/) 的**完整本地化复刻**：页面布局、视觉风格、3D 对局玩法、动画和音效都保持原样，但**不依赖任何外网资源**，断网也能玩。

- 原站版本：`0.8.55`（构建号 `mvob1c8t`）
- 已本地化：5000+ 个资源文件，约 100 MB（1025 只宝可梦叫声、971 套 PMD 动画图集、736 个字体文件、12 个生态区贴图、全部音乐与 UI 素材）
- 联机接口：用本地服务模拟，进度写进本机 `_save` 目录

---

## 一、怎么启动

### Windows（最简单）

双击 **`启动游戏.bat`**，浏览器会自动打开 `http://127.0.0.1:8730/`。

### 手动启动（任何系统）

```bash
node serve.js          # 然后浏览器打开 http://127.0.0.1:8730/
node serve.js --open   # 启动后自动开浏览器
PORT=9000 node serve.js # 换端口
```

端口被占用时会自动往后顺延（8730 → 8731 → …），终端里会打印实际地址。

> **前提**：需要 Node.js（任意 14+ 版本）。项目**零第三方依赖**，不用 `npm install`。

### ⚠️ 不要直接双击 index.html

游戏是 ES Module + 动态 `fetch` 加载数据的结构，浏览器在 `file://` 协议下会拦截模块加载和跨文件请求，直接双击只会白屏。必须通过上面的本地服务打开。

## 三、存档

### 进度存在哪

真实进度由本地服务写入项目下的 **`_save/`** 目录：

```
_save/
├── account.json   # 账号（游客 id、昵称、token）
└── profile.json   # 游戏进度（星光、邦币、图鉴、联盟、记录…）
```

浏览器 `localStorage` 里只存语言、主题这类偏好，删了不影响进度。

### 全解锁存档（项目根目录 `全解锁存档.json`）

一份已经把所有可解锁内容全部打开的档案，直接用它覆盖当前进度：

1. 点右下角 💾 圆钮（或 `Ctrl+Shift+S`）
2. **导入存档** → 选 `全解锁存档.json` → 确认

导入后会变成：

| 项目 | 数值 |
| --- | --- |
| 联盟成员 | **79 / 79**（本版本全部可玩宝可梦） |
| 图鉴 | **151 / 151**（关都全图鉴点亮） |
| 异色 / 经典异色 | **78 / 78 家族全开**（更衣室里可直接装备） |
| 更衣室外观 | **每只宝可梦 5 套全解锁**（普通 / 异色 / 经典异色 / 精通 I / 精通 II） |
| 收藏队伍 | 6 只（妙蛙种子 / 小火龙 / 杰尼龟 / 绿毛虫 / 独角虫 / 波波）|
| 星尘 | **1,000,000**（商店货币） |
| 邦币 | **1,000,000**（宝藏转盘货币） |

说明：

- 这个存档**不带账号信息**，导入时不会覆盖你的昵称和本机账号，只覆盖游戏进度。
- 79 是**游戏本身的可玩名单长度**——数据里虽然有 1025 只，但只有这 79 只带挑战/招式组，能进联盟开局；其余的点亮图鉴但不参战。
- 更衣室外观的解锁键是 `cosmetics` 里的 `look:<成员id>:1` / `:2`，异色和经典异色则查 `shinies` / `classics` 里的家族根；这三样都已经填满。
- 解锁前的原始档案已备份在 `_save/profile.bak.json`，想退回去把它改名成 `profile.json` 即可。
- 想从头开始玩，见下面「重置进度」。

### 商店与两种货币

| 货币 | 用在哪 | 怎么来 |
| --- | --- | --- |
| **星尘**（Polvo Estelar） | 主菜单「商店」买背包道具 | 对局结算、成就、任务 |
| **邦币**（Bonkoin） | 「宝藏」转盘抽奖 | 对局击败守卫/首领 |

商店价格按**当天购买次数递增**：第 1 个 150，第 2 个 225，第 3 个 300（每次多加「基础价的一半」，也就是 150 → 225 → 300 → 375…）。每人每件每天有购买上限，按 UTC 00:00 重置。背包里同一种道具最多存 9 个。

> 离线版这里做过一处修复：原版是「客户端本地算好 → 交给服务端确认」，而本地接口早期只做空响应，导致**点购买后钱不扣、东西也没进包**。现在 `local-api.js` 按同样的价格公式复算了一遍，购买能正常扣款入库。

### 研究所（Lab）升级

研究所里同样的坑也一起补上了。现在这三类操作都会真正落盘：

| 操作 | 花什么 | 说明 |
| --- | --- | --- |
| **升级**（伤害/韧性/敏捷…共 24 项） | 星尘 | 每项有等级上限（1~8 级），满级后按钮变灰 |
| **永久解锁道具**（58 种持有物） | 星尘 | 买断制，价格 150 ~ 3500，买过就不再重复收费 |
| **档案库归档**（把不想要的道具踢出掉落池） | 免费 | 需要先把「档案库」升到 1 级才有栏位（每级 +5 格） |

升级价格的算法和原站完全一致：基础价按等级指数增长，最后再乘 **0.85** 并四舍五入到 **5 的倍数**。举几个实测值（就是界面显示的数字）：

- 训练（+4% 伤害）：85 → 120 → 165 → 235 → 325 → 455 → 640 → 895（8 级满）
- 敏捷（+2.5% 速度）：100 → 150 → 215 → 310 → 450 → 655（6 级满）
- 档案库（+5 格）：510 → 1020 → 1700 → 2550 → 3400 → 4675（6 级满）
- 4 号招式槽：一次性 1275

> 这些数字都是从 `assets/news-*.js` 里的原始数据表逐项核对过的，不是拍脑袋估的。实测连点 7 级，界面价和实际扣款每一级都对得上。

### 委托（每日/每周任务）与成就

这两块原来也是「点了没反应」，现在整条链路都通了：

| 入口 | 内容 | 说明 |
| --- | --- | --- |
| 主菜单 **委托** | 每天 3 个日常 + 3 个周常，各配一个「全清额外奖励」 | 每天/每周按 UTC 自动换一批 |
| 主菜单 **成就** | 71 条长期目标（含隐藏成就） | 达成后领星尘，部分带称号 |

几个关键规则（都跟原站一致）：

- **任务进度由服务端记账**。原版就是客户端只上报「这局打了多少」，进度由后端累加。离线版在 `/runs/:id/finish` 里按同样的口径累加，所以打完一局回委托页就能看到进度条动了。
- **奖励星尘**：日常三格 60 / 100 / 160，周常三格 300 / 450 / 700；全清额外奖励日常是 `50 × 连续天数`（最高 250）外加一个随机道具，周常固定 500 星尘 + 3 个道具。
- **任务种类按「周期序号 + 槽位」确定性抽取**，所以你不会因为刷新页面就换一批任务；每日可重掷 1 次（换一个），重掷后进度归零。
- **委托领取不做进度校验**。原版服务端会核对进度，离线版本地只认「是否已领过」，图省事也不会卡住你——反正是自己玩的单机档。

> 任务池、委托表、奖励数值全部是从 `assets/news-*.js` 里原样抽出来存进 `mock/task-data.json` 的（71 条委托 + 每日 6/8/6 条、每周 4/4/5 条任务池），不是手抄的。


### 导出 / 导入

点右下角的 **💾** 圆钮（或按 `Ctrl+Shift+S`）打开存档面板：

- **导出存档** → 下载一个 `pokebonk-save-YYYYMMDD-HHMM.json`，里面同时打包了服务端档案和浏览器偏好。
- **导入存档** → 选文件，确认后写回 `_save/` 并自动刷新页面。

换电脑时把整个项目文件夹拷过去也行；只想搬进度就带那个 json 文件。

### 重置进度

```bash
# 关掉服务后执行
rm -rf _save          # macOS / Linux / Git Bash
```

Windows 资源管理器里直接删 `_save` 文件夹即可。下次启动会重新走初始伙伴选择。

## 四、离线是怎么做到的

原站是 Vite 打包的单页应用，难点有三个：

1. **资源路径带版本哈希** — 原代码用 `./assets/xxx.png?v=<hash>` 相对路径取资源。因为保留了原始目录结构和文件名，所以**一个路径都不用改**。
2. **服务端接口** — 原代码把 `https://api.pokebonk.com` 硬编码在 `assets/main-*.js` 里。离线版把它改成**同源相对路径**，由 `serve.js` + `local-api.js` 接管，等价于把官方后端搬到本机。
3. **人机验证** — 原站注册要过 Cloudflare Turnstile，且只在 `pokebonk.com` 域名下用正式 key。离线版用 `offline/patch.js` 桩掉 `window.turnstile`，直接放行。

`offline/patch.js` 还会在最早时机拦截一切跨域请求（`fetch` / `XHR` / `beacon`）和外部 `<script>` 注入，保证**运行时零外网请求**。调试时想临时放行，加参数 `?pb-online=1`。

### 本地模拟了哪些接口

`local-api.js` 覆盖了启动、登录、选伙伴、开局、结算、商店、图鉴、排行榜等主链路：

- `POST /auth/guest` → 发一个本机账号
- `GET /profile` → 读 `_save/profile.json`
- `POST /runs` → 发一个对局 id 和随机种子
- `POST /runs/:id/finish` → 结算并写回星光 / 邦币 / 图鉴进度
- `GET /save/export` · `POST /save/import` → 存档快照读写
- 排行榜、氏族、邮件、组队等**联机向**接口返回空集合兜底，保证界面不报错

## 五、目录结构

```
pokebonk/
├── 启动游戏.bat           # Windows 一键启动
├── start.sh               # macOS / Linux 启动脚本
├── 全解锁存档.json          # 联盟 79/79 + 图鉴 151/151 的存档
├── serve.js               # 零依赖静态服务器 + 接口路由
├── local-api.js           # 本地接口实现（读写 _save）
├── index.html             # 原站入口（注入了离线补丁与存档面板）
├── offline/
│   ├── patch.js           # 请求拦截 + Turnstile 桩
│   └── save-manager.js    # 存档导入导出面板
├── assets/                # 全部本地化资源（脚本、图集、音乐、字体）
├── data/                  # 宝可梦 / 招式 / 道具 / 图鉴 / i18n 数据
├── icons/  social/        # PWA 图标与分享图
├── mock/                  # 初始状态快照 + 任务/委托数据表（task-data.json）
└── _save/                 # 运行时生成的存档（可删）
```

- 主菜单九个分页（图鉴 / 研究所 / 商店 / 排行榜 / 战队 / 设置…）逐个点开，无 404、无报错
- 存档导出 → 清空进度 → 导入 → 星光 / 邦币 / 联盟成员数完全还原

## 七、已知限制

- **能上场的只有 79 只**：数据包里存了 1025 只的图鉴资料，但只有 79 只配了挑战条件和招式组，能真正进联盟开局；其余只做图鉴展示，不能参战。这也是「联盟 x/79」的由来。
- **没有真联机**：排行榜、氏族、好友、合作模式都是本地空数据，不会有其他玩家。
- **结算不排名**：对局结束会提示「游戏未计入排名 · 未通过服务器校验」，因为本地不跑官方校验；奖励（星光、邦币）照常发放并落盘。
- **账号是假的**：游客账号只在本机有效，换成「正式账号」也是本地改名，不连云。
- **首次进入略慢**：本地服务要读 100 MB 资源，第一次加载 5～8 秒属正常，之后有浏览器缓存会快很多。
